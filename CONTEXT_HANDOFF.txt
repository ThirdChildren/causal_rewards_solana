PROJECT ONE-LINER
-----------------

proof-of-contribution, it asks: did a contribution cause measurable additional
value vs a credible counterfactual ("Proof of Additionality")? Grant-scoped MVP,
20 weeks, devnet only. Full context: mvp/CLAUDE.md (the source of truth for
invariants, layout, milestones). Protocol semantics live in
mvp/causal-rewards/specs/ and WIN over any implementation.

INTERFACE / SERIALIZATION DECISIONS OTHER COMPONENTS DEPEND ON
================================================================================
- ONE canonical byte form governs every hash + Merkle root. Owner = specs/
  (serialization.md). verifier-cli/reference/ is the conformance oracle; any component
  that hashes/roots data MUST match it. Do not introduce a second encoder.
- Numbers are strings everywhere in hashed artifacts (integer-scaled). Serializer raises
  on int/float on purpose.
- Hash = SHA-256 throughout (revisit compute-unit cost with solana-program-engineer at
  M2; both SHA-256 and Keccak have Solana syscalls; not expected to change).
- Merkle: domain-separated, odd-node promotion (avoids CVE-2012-2459), empty root = 32
  zero bytes. Per-tree ASCII domain tags.
- Seed: commitment = SHA256("CRP-seed-commit-v1"||seed) frozen pre-reveal; revealed
  32-byte seed drives a length-prefixed PRF for assignment. On-chain program MUST verify
  revealed seed against stored commitment (structural freeze-before-reveal).
- Simulator assignment derivation is isolated in simulator/src/depin_sim/assignment.py
  (placeholder ALPHA_DERIVATION) — swap to the canonical derivation at M2/M3.
